# OpenChatMix 2.5.5

The Arctis Nova Elite gets its own equalizer.

## Highlights

- **Nova Elite equalizer (experimental).** The *Headset* tab now has the equalizer for the Elite too: the
  SteelSeries presets (Flat, Bass Boost, Focus, Smiley), the custom 10-band curve, game presets and your
  saved presets. It works in the base station itself, like the one in GG's *Engine* tab, so SteelSeries GG
  can stay closed.

It's sent the way GG sends it, as [@Lasfecas](https://github.com/Lasfecas)'s USB capture in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6) shows. It's not yet
confirmed on a real Elite, so if the sound does not change, please tell us in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6) with a log
(*Settings → General → Diagnostics*).

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.5.5-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
