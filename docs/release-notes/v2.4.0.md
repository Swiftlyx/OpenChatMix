# OpenChatMix 2.4.0

Plugins for what you hear, a device per group without virtual cables, and output switching that follows
a wireless headset's power.

## Highlights

- **VST plugins on Game, Chat and Media.** In virtual device mode the *Equalizer* tab has a *Plugins* list
  for each channel, like the microphone's: drag to reorder, a switch per plugin, click to open its window.
  A convolver with impulse responses, crossfeed, loudness or a bass plugin you own shapes the sound without
  a system-wide driver. Plugins run in stereo before the channel's volume, so a compressor does not undo
  the ChatMix balance, and nothing loads for a channel without plugins.
- **DeepFilterNet on Chat.** The AI noise suppression plugin
  ([`DeepFilterNet-OpenChatMix.dll`](https://github.com/Swiftlyx/OpenChatMix/releases/latest/download/DeepFilterNet-OpenChatMix.dll))
  also works on the Chat channel, where it removes noise from the voices of others.
- **A device per group, no virtual cables needed.** With virtual device mode off, *Settings → Audio →
  Audio routing* lets each group play on its own device, for example Game and Chat on the headset and Media
  on the speakers. Windows sends the group's apps there, ChatMix still balances Game and Chat wherever they
  play, and OpenChatMix clears the choice again when it exits.
- **Output devices follow your wireless headset.** The base station or dongle stays in Windows as a
  playback device while the headset is off, so OpenChatMix now goes by the headset's own status: with
  *Switch when a device disconnects* the sound moves to the next device when you switch the headset off,
  and with *Return to a device that reconnects* it comes back when you switch it on. Requested by
  [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5) and
  [@liquidshadowfoxx](https://github.com/liquidshadowfoxx) in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6).
- **Smaller things.** Plugin latency now counts in the latency shown for the microphone chain and virtual
  device mode; the audio threads no longer wait for a VST 3 plugin's window; *Keep levels at 100%* also
  holds a cable whose ends were renamed in the Windows sound settings. The Nova 7 Gen 2 protocol equalizer
  is confirmed on the Arctis Nova 7 (`22A1`), reported by [@zer0ed](https://github.com/zer0ed) in
  [#7](https://github.com/Swiftlyx/OpenChatMix/issues/7).

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

| Arctis Nova 7, Nova 7 Gen 2 | Works, reported by [@zer0ed](https://github.com/zer0ed) in [#1](https://github.com/Swiftlyx/OpenChatMix/issues/1) and [#2](https://github.com/Swiftlyx/OpenChatMix/issues/2); the Gen 2 protocol equalizer works on `22A1` ([#7](https://github.com/Swiftlyx/OpenChatMix/issues/7)) |

| Arctis Nova 7X, Arctis 7P+ / 7X+, Nova 5X | Untested |

Any other headset or speakers work with the panel, the hotkeys and the mouse wheel.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.4.0-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
