# OpenChatMix 1.0.0

First public release of OpenChatMix: ChatMix for SteelSeries Arctis headsets on Windows without
SteelSeries GG or Sonar. A single executable of about 1 MB that idles at 0% CPU and a few megabytes of
memory.

## Highlights

- The headset's ChatMix dial balances game and chat audio through per-app volume. No drivers and no
  virtual audio devices are installed, and no latency is added.
- The ChatMix icon is shown on the GameDAC display while OpenChatMix runs. The knob's volume mode
  is left untouched.
- Apps go into Game, Chat or Media groups. Media apps, such as music players, ignore ChatMix; the
  Media group can be turned off.
- Global hotkeys with an on-screen popup work with any output device, even without a SteelSeries
  headset, where the balance can be set to the exact percent. Optional hotkeys mute chat and switch
  EQ presets, and a single key (such as a keyboard's volume knob) can be a hotkey.
- Optional updates from the GitHub releases, installed with one click after a SHA-256 check.
- A Material 3 tray panel in English and Ukrainian: automatic, light or dark theme, your Windows
  accent or any color, and an Acrylic, Mica or solid background.
- Native headset settings with the SteelSeries Engine EQ presets, a 10-band custom EQ, and EQ
  presets saved as files you can share.
- A screensaver for the GameDAC display: stars, a clock, Game of Life or your own GIF while no
  sound plays, so the OLED does not burn in.
- An optional virtual device mode: Game and Chat from two virtual audio cables are mixed into the
  headset, as Sonar does. Chat apps go to the Chat cable and the rest to the Game cable on their
  own. The cables are switched on and made the Windows defaults only while the mode runs.
- In virtual device mode, a 10-band parametric equalizer for Game and Chat that works with any
  headset, drawn like Sonar's, with Bass Boost, Voice Clarity, Treble Boost, Smart Volume, built-in
  presets and the presets of your Sonar installation. Game presets also work on the headset's own
  EQ.
- Optional extras: ducking while chat plays, per-game profiles, a popup for the ChatMix wheel on
  headsets without a display, and a low battery warning.
- Smooth animations on high refresh rate monitors.

Feedback on untested models is welcome. Please attach `OpenChatMix.log` (enable it with `Log=1` in
`%APPDATA%\OpenChatMix\OpenChatMix.ini`).

## Install

1. Quit SteelSeries GG and disable it at startup.
2. Set the headset as the Windows output device instead of *SteelSeries Sonar – Gaming*.
3. Download `OpenChatMix.exe` (or the zip) and run it. It adds itself to startup. You can turn
   this off in Settings.

The binary is not code-signed, so SmartScreen may ask for confirmation on the first run. Some
antivirus programs may also flag it as a new, unsigned program; these are false positives. Compare
the file with `SHA256SUMS.txt`, read the source code in the repository or build it yourself.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-1.0.0-win-x64.zip`: the app with README and LICENSE.
- `SHA256SUMS.txt`: checksums.
