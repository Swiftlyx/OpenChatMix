# OpenChatMix 2.5.6

The Nova Elite and Nova 7 Gen 2 get a parametric equalizer on the *Headset* tab.

## Highlights

- **Parametric headset equalizer.** On the Arctis Nova Elite and Nova 7 Gen 2 the *Headset* tab now has
  the same response graph as the *Equalizer* tab: ten filters, each with its own type, frequency, gain and
  Q. Drag a point left or right for the frequency, up or down for the gain, turn the mouse wheel over it
  for Q, or set it all in the band editor below. It runs in the headset itself, so GG can stay closed.
- **GG's game presets, as GG sends them.** On these headsets a game preset goes on with its own filters
  instead of being fitted to ten bands. For the presets in [@Lasfecas](https://github.com/Lasfecas)'s USB capture in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6), the bytes are
  the same as GG's.
- **Presets keep the filters.** Saved headset presets hold the filters, plus the closest ten-band curve, so
  they still load on headsets with fixed bands.

Other headsets keep their ten band sliders. Both equalizers are still experimental on these headsets: the
peak filter is confirmed, while shelf and pass filters follow the vendor's protocol description. If one of
them doesn't sound right, please tell us in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6) or [#7](https://github.com/Swiftlyx/OpenChatMix/issues/7).

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over; a custom curve becomes the same filters.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.5.6-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
