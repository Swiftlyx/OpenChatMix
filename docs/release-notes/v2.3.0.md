# OpenChatMix 2.3.0

AI noise suppression for the microphone as an optional plugin, and fixes for a hang and a plugin crash.

## Highlights

- **AI noise suppression (optional).** [`DeepFilterNet-OpenChatMix.dll`](https://github.com/Swiftlyx/OpenChatMix/releases/latest/download/DeepFilterNet-OpenChatMix.dll)
  is OpenChatMix's build of [DeepFilterNet](https://github.com/Rikorose/DeepFilterNet) by Hendrik Schröter:
  a neural network that removes noise more thoroughly than the built-in RNNoise, with its DeepFilterNet3
  model inside. Download it and add it in *Settings → Microphone → Plugins → Add plugin*, like a VST plugin.
  - *Max noise reduction* (6–60 dB or unlimited) and *Post-filter* appear below the plugin list. Lower
    values leave a little of the room in, which sounds more natural.
  - It adds about 20 ms and takes about 3% of one CPU core. Nothing of it is loaded until you add it, and
    OpenChatMix itself stays as small as before.
  - The chain's latency on the *Microphone* page now includes what plugins add.
- **No more freezes with the visualizer.** OpenChatMix could stop responding and be closed by Windows while
  the GameDAC visualizer was set to music and video: the check whether media plays asks other processes
  and ran on the app's main thread. It runs on a thread of its own now.
- **Plugins that crash on unload** (such as Supertone Clear) no longer take OpenChatMix down when the
  microphone chain stops or the app exits, and the app volumes are always restored first.
- **Logs.** `Log=1` set in `OpenChatMix.ini` while OpenChatMix runs is kept, and a log file still held by
  an instance that is ending no longer leaves the new one without a log. Reported by
  [@liquidshadowfoxx](https://github.com/liquidshadowfoxx) in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6).
  With the log on, a hang writes `OpenChatMix-hang-<time>.dmp` next to it, to find the cause.
- **Arctis Nova Elite confirmed**: the ChatMix dial and the battery work, reported by
  [@liquidshadowfoxx](https://github.com/liquidshadowfoxx) in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6).

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over. The *VST plugins* section of the microphone is now called *Plugins*.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.3.0-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
