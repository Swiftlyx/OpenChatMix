# OpenChatMix 2.5.2

The Nova Pro Wireless gets the settings its base station has had all along.

## Highlights

- **Noise control on the Nova Pro Wireless.** The *Headset* tab switches between off, transparency and
  ANC, with the transparency level, and follows the headset's own button.
- **Bluetooth options.** Turn Bluetooth on together with the headset, and lower or mute the game during
  calls.
- **Spare battery.** The battery charging in the base station shows next to the headset's, on the
  *Headset* tab and in the tray, and both update as soon as the base station reports a change.

Requested by [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5); the commands are the ones [NovaPanel](https://github.com/thibautgnt/NovaPanel) documents for this base station.
If one of them does not apply on yours, please tell us in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5).

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.5.2-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
