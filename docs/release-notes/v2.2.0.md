# OpenChatMix 2.2.0

Experimental support for the Arctis Nova Elite, and a log that helps add new SteelSeries headsets.

## Highlights

- **Arctis Nova Elite (experimental).** The ChatMix dial and the battery of the Nova Elite (`2244`,
  `2270`), built from published descriptions of its protocol: captures of a real base station in
  [HeadsetControl #481](https://github.com/Sapd/HeadsetControl/issues/481) and the device definitions of
  Linux-Arctis-Manager. It has not been tried on the headset yet, and the Elite's settings, equalizer
  and screen are not supported. Requested in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6).
- **A log for headsets OpenChatMix does not know.** With the log on and no supported headset
  connected, a SteelSeries headset is recognized by its audio devices, and the log lists its HID
  collections and the reports it sends. OpenChatMix only reads them and sends nothing to such a
  headset, so a log is all it takes to add a new model; no USB capture tools are needed.

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Testing a Nova Elite

1. Quit OpenChatMix from the tray menu (*Quit*); it saves its settings when it exits.
2. Set `Log=1` in `%APPDATA%\OpenChatMix\OpenChatMix.ini` and start OpenChatMix again.
3. Turn the ChatMix dial both ways, press the base station's buttons, and turn the headset off and on.
4. Attach `OpenChatMix.log` from the same folder to [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6),
   and say whether the balance and the battery beside the app's name follow the headset.

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

## Supported headsets

| Headset | Status |
| --- | --- |
| Arctis Nova Pro Wired | Tested |
| Arctis 7+ | Tested |
| Arctis Nova Pro Wireless | Works, reported by [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5) |
| Arctis Nova 7, Nova 7 Gen 2 | Works, reported by [@zer0ed](https://github.com/zer0ed) in [#1](https://github.com/Swiftlyx/OpenChatMix/issues/1) and [#2](https://github.com/Swiftlyx/OpenChatMix/issues/2); the Gen 2 equalizer is experimental ([#7](https://github.com/Swiftlyx/OpenChatMix/issues/7)) |
| Arctis Nova 7X, Arctis 7P+ / 7X+, Nova 5X | Untested |
| Arctis Nova Elite | Experimental: ChatMix dial and battery ([#6](https://github.com/Swiftlyx/OpenChatMix/issues/6)) |

Any other headset or speakers work with the panel, the hotkeys and the mouse wheel.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.2.0-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `SHA256SUMS.txt`: checksums.

The binary is not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the file with
`SHA256SUMS.txt`, read the source code or build it yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces) is listed in `THIRD_PARTY_NOTICES.md`.
