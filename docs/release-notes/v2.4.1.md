# OpenChatMix 2.4.1

Experimental settings for the Arctis Nova Elite.

## Highlights

- **Nova Elite settings on the *Headset* tab.** Microphone volume, sidetone for the boom and the built-in
  microphone, mute LED brightness, noise control (off, transparency or ANC) with its level, volume
  limiter, line out with the stream mix, display brightness, screen dimming and home screen, auto
  power-off and the Bluetooth options. The tab reads the current values from the base station, follows
  changes made on it or in SteelSeries GG and saves them to the headset.
- **Experimental.** The settings follow the Elite's protocol description and the base station's events
  in the log from [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6); auto power-off and saving were confirmed by [@liquidshadowfoxx](https://github.com/liquidshadowfoxx). If a setting does not
  apply or shows a wrong value, please tell us in [#6](https://github.com/Swiftlyx/OpenChatMix/issues/6) and attach `OpenChatMix.log` (set `Log=1` in
  `%APPDATA%\OpenChatMix\OpenChatMix.ini` while OpenChatMix is closed). The Elite's own equalizer is not supported yet; the equalizer of virtual device mode
  works with it.

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

Any other headset or speakers work with the panel, the hotkeys and the mouse wheel.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.4.1-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
