# OpenChatMix 2.1.0

A screensaver that stays on, Bluetooth headphones' battery, and an experimental equalizer for the
newer Arctis Nova 7 firmware.

## Highlights

- **Screensaver on until you turn it off.** The *Screensaver on/off* hotkey (formerly *Screensaver
  now*) keeps the GameDAC screensaver on until you press it again, also while sound plays. Turning the
  knob or a change made in OpenChatMix shows the GameDAC's own screen for three seconds, then the
  screensaver comes back. Requested by [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5).
- **The screensaver no longer stops by itself** on the Nova Pro Wireless: the battery and 2.4 GHz link
  reports the base station sends on its own no longer count as using the GameDAC.
- **Bluetooth icon like the headset's LED** (Nova Pro Wireless): steady with a device connected,
  blinking slowly while Bluetooth waits for one and fast while it pairs. Suggested by [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5).
- **Battery of Bluetooth headphones.** When Windows gets the level from them, it shows beside the app's
  name, in the tray tooltip, as the tray icon at the even balance and in the low battery popup.
- **Experimental equalizer for the Nova 7 Gen 2 protocol.** The Nova 7 Gen 2 (`227E`) and the Nova 7
  models on the newer firmware (`22A1`, 7X `229E` / `22A5` / `22AD`, Diablo IV `22A9`, WoW `22AB`)
  ignored the older equalizer command. The curve is now sent as ten peak filters, as
  Linux-Arctis-Manager describes their protocol. It is not confirmed on these headsets yet, so the
  *Headset* tab marks it as experimental. Reported by [@zer0ed](https://github.com/zer0ed) in [#7](https://github.com/Swiftlyx/OpenChatMix/issues/7).
- **Smaller things.** After a SteelSeries headset disconnects, the panel no longer shows its last
  battery level, and the Ukrainian translation reads more naturally with the same terms as Windows.

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- 2.0.0 and 1.0.0 find this version on their own once a day (*Settings → Updates*), download it,
  check it against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over, including the screensaver hotkey under its new name.

## Supported headsets

| Headset | Status |
| --- | --- |
| Arctis Nova Pro Wired | Tested |
| Arctis 7+ | Tested |
| Arctis Nova Pro Wireless | Works, reported by [@Katan21](https://github.com/Katan21) in [#5](https://github.com/Swiftlyx/OpenChatMix/issues/5) |
| Arctis Nova 7, Nova 7 Gen 2 | Works, reported by [@zer0ed](https://github.com/zer0ed) in [#1](https://github.com/Swiftlyx/OpenChatMix/issues/1) and [#2](https://github.com/Swiftlyx/OpenChatMix/issues/2); the Gen 2 equalizer is experimental ([#7](https://github.com/Swiftlyx/OpenChatMix/issues/7)) |
| Arctis Nova 7X, Arctis 7P+ / 7X+, Nova 5X | Untested |

Any other headset or speakers work with the panel, the hotkeys and the mouse wheel.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.1.0-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `SHA256SUMS.txt`: checksums.

The binary is not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the file with
`SHA256SUMS.txt`, read the source code or build it yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces) is listed in `THIRD_PARTY_NOTICES.md`.
