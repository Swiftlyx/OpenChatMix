# OpenChatMix 2.5.1

GG's presets are back after GG's update, with Engine's added, and long preset lists got search.

## Highlights

- **Presets from SteelSeries GG again.** Current GG moved Sonar's database, so its presets had vanished
  from the menus. They are read from the new place, chat presets in their new format too, and Sonar's
  media presets now go to the Media channel. 46 presets GG wrote in a slightly broken format are no
  longer skipped.
- **Engine's presets.** GG's Engine keeps game and microphone presets of its own. Those Sonar lacks
  (mostly console and mobile games) join the list, now called *From SteelSeries GG*.
- **Presets for the game in app profiles.** The *Game equalizer* menu of a profile starts with GG's
  presets made for that game, under *For this game*: found through GG's game library, or by the game's
  name.
- **Search in preset menus.** Start typing in an open preset menu and it filters; a *Type to search…*
  hint at the top says so. Ctrl+A, Ctrl+C, Ctrl+V, Ctrl+X and Ctrl+Backspace work, and Esc clears the
  search first. *Manage presets…* moved up, above GG's long list.
- **Smooth long lists.** Menus and pages with hundreds of presets scroll without lag, and their
  scrollbars can be dragged.
- **Smaller things.** The *Game presets* menu on the *Headset* tab no longer repeats the headset's own
  presets. On the Nova 7 Gen 2 the equalizer counts down to the delayed save and then says *Done*.

The full list is in [CHANGELOG.md](https://github.com/Swiftlyx/OpenChatMix/blob/main/CHANGELOG.md).

## Upgrading

- Earlier versions find this one on their own once a day (*Settings → Updates*), download it, check it
  against `SHA256SUMS.txt` and restart. You can also replace `OpenChatMix.exe` by hand.
- Your settings carry over.

## Files

- `OpenChatMix.exe`: the app, portable.
- `OpenChatMix-2.5.1-win-x64.zip`: the app with both READMEs, the license and the third-party notices.
- `DeepFilterNet-OpenChatMix.dll`: the optional AI noise suppression plugin, built from `tools/deepfilter`.
- `DeepFilterNet-NOTICES.txt`: the licenses of DeepFilterNet and the Rust crates inside the plugin.
- `SHA256SUMS.txt`: checksums.

The binaries are not code-signed, so SmartScreen may ask for confirmation on the first run, and some
antivirus programs may flag a new, unsigned program; these are false positives. Compare the files with
`SHA256SUMS.txt`, read the source code or build them yourself. Third-party code (RNNoise, the VST 3 SDK
interfaces, DeepFilterNet in the plugin) is listed in `THIRD_PARTY_NOTICES.md`.
